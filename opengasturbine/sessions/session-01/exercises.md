# Coding tasks: Session 1

1. **Easy.** Compute `ideal_efficiency` for r = 3, 6 and 12. Predict first how much the efficiency rises each time r doubles.
2. **Stretch.** Write `pressure_ratio_for(eta)` that returns the pressure ratio needed for a given ideal efficiency, and test it: `pressure_ratio_for(0.55)` should be about 16.4.
3. **Explain in your own words.** Explain why the exhaust of a gas turbine is hot, and what that has to do with the efficiency never reaching 1.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
