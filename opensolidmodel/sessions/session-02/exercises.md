# Coding tasks: Session 2

1. **Easy.** Compute `section_properties` for `l_section(50, 50, 4)` and `l_section(50, 50, 6)` and predict first by what percent Ixx changes.
2. **Stretch.** Add a function `rectangular_tube(w, h, t)` built from an outer polygon and an inner one with a sign of -1, and check Ixx against (w h^3 - (w - 2t)(h - 2t)^3) / 12.
3. **Explain in your own words.** Explain why a hole on the neutral axis changes Ixx so little, using the idea of y squared.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
