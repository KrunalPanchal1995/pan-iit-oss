# Project form (Hello FOSS)

**Project name:** openeclipse

**Short description:** Learn eclipse geometry, shadow cones, the eclipse limit and the Saros cycle, and predict eclipse dates, in 3 sessions.

**Full description:** openeclipse is a beginner-friendly learning repo about solar and lunar eclipses. In three short sessions you go from two almost-equal discs in the sky, to the umbra and penumbra cones, the width of the totality path and the eclipse limit near the Moon's node, to a small simulation built from the Moon's mean motions that predicts new moons in eclipse seasons, compares itself with published eclipses, and finds the 18-year Saros cycle on its own. Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment), and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. The model is an educational approximation: for real dates, times and maps use published eclipse tables. The repo stops at Session 3 on purpose; a Target animation and a roadmap show where the community can take it next. Safety: never look at the Sun without certified eclipse glasses.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, JavaScript, LaTeX
