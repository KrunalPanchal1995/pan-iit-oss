# Project form (Hello FOSS)

**Project name:** openvectors

**Short description:** Learn vectors as arrows, components and the dot product, then simulate a ferry that corrects its heading, in 3 sessions.

**Full description:** openvectors is a beginner-friendly learning repo about vectors. In three short sessions you go from arrows that add head to tail, to components, trigonometry and the dot product with an exact design answer for a ferry (which heading lands it opposite, which heading crosses fastest), to a time-stepping simulation of a boat in a river whose current is strongest mid-stream, with a side wind and a feedback controller that corrects the heading. The simulation is validated against the exact formulas, tested for sensitivity to the current, and pushed into a failure case (a current faster than the boat). Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment), and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. The repo is intentionally incomplete: a Target animation and a roadmap show where the community can take it next, such as look-ahead control, wind-robust steering and river bends.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, JavaScript, LaTeX
