# Project form (Hello FOSS)

**Project name:** openexperiment

**Short description:** Learn fair tests, sensor calibration and experimental design (randomisation, replication, factorial runs) from scratch in 3 sessions.

**Full description:** openexperiment is a beginner-friendly learning repo about doing experiments properly. In three short sessions you go from the idea of a fair test (change one thing, measure the same way, repeat) and the difference between accurate and precise, to calibrating a simulated temperature sensor with a least-squares line (slope and intercept with standard errors, inverse prediction, repeatability, quantisation, bias versus random error), to experimental design: randomisation against drift, how many replicates you need, a 2x2 factorial design that finds an interaction which one-factor-at-a-time misses, and a calibration across temperature and supply voltage. Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment) and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. All sensors are simulated with known settings, so every claim is checked against the truth. The repo is intentionally incomplete: a Target animation and a roadmap show where the community can take it next.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, JavaScript, LaTeX
