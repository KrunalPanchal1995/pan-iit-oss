# Project form (Hello FOSS)

**Project name:** opensorting

**Short description:** Compare bubble, insertion, selection, merge and quick sort by comparisons, swaps and time, from scratch in 3 sessions.

**Full description:** opensorting is a beginner-friendly learning repo about one question: why can a smarter sorting algorithm be far faster on a big list even though both give the same sorted answer? In three short sessions you go from sorting playing cards by hand (bubble and insertion sort as moves you can count), to five algorithms in plain Python with comparison and swap counters, correctness tests and the formulas n(n-1)/2 and n log2 n, to measured growth curves on log-log axes, quicksort's worst case and its cures, a hybrid merge/insertion sort, memory use and Python's own sorted(). Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment), and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. The repo is intentionally incomplete: a Target animation and a roadmap show where the community can take it next, such as a live algorithm race, run-detecting merge sort, three-way quicksort and counting sort.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, JavaScript, LaTeX
