# Coding tasks: Session 1

1. **Easy.** Change P, D and f in `lesson.py` and predict the peak before you run it. Check your prediction with `storm_peak`.
2. **Stretch.** Write `longest_safe_storm(P, f)` that finds the longest duration (in 0.5 h steps up to 12 h) for which the peak still exceeds 100 m3/s.
3. **Explain in your own words.** Explain why the peak falls when the same rain is spread over a longer time, using the words intensity, soak-in and delay.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
