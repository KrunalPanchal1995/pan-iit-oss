# Coding tasks: Session 1

1. **Easy.** Change the starting value in `lesson.py` to y0 = 3 and predict the blow-up time before running; then compare with the RK4 value.
2. **Stretch.** Write a function that finds the time at which y first passes 1000 for dy/dt = y^2, y0 = 1, and compare it with 1/y0 - 1/1000.
3. **Explain in your own words.** Explain in your own words why dy/dt = y has no blow-up but dy/dt = y^2 has, and why a steepening wave moves energy to short waves.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
