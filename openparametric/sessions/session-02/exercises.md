# Coding tasks: Session 2

1. **Easy.** Run `design(500, 100, 40, 1.0)` and `design(500, 300, 40, 1.0)` and predict first which rule governs in each case.
2. **Stretch.** Add a third material, for example a plastic with E = 3000 MPa, yield 60 MPa and density 1200 kg/m^3, to `MATERIALS` and find the length at which it stops being possible with the plates that are sold.
3. **Explain in your own words.** Explain why checking the deflection formula by integrating the beam equation numerically is a better test than recalculating the same formula.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
