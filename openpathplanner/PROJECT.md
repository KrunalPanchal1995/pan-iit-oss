# Project form (Hello FOSS)

**Project name:** openpathplanner

**Short description:** Learn path planning: BFS, Dijkstra, A*, RRT and RRT* for a warehouse robot, from scratch in 3 sessions.

**Full description:** openpathplanner is a beginner-friendly learning repo about path planning and obstacle avoidance, the problem every warehouse robot, delivery robot and autonomous vehicle must solve. In three short sessions you go from a robot on a grid that must walk around a wall, to graph search written by you (breadth-first search, Dijkstra with a priority queue, and A* with an admissible heuristic that expands fewer nodes and still finds the cheapest route), to continuous space with RRT, collision checks for circles and rectangles, path smoothing, RRT* and a comparison with grid A*. Everything is validated: against hand-checkable grids, against the exact shortest path around a wall, and with a failure case (a narrow passage that RRT rarely finds). Each session has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. The repo is intentionally incomplete: a Target animation and a roadmap show where the community can take it next. Educational simplified models only, not for controlling real robots or vehicles.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, JavaScript, LaTeX
