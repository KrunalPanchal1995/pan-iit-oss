# Coding tasks: Session 2

1. **Easy.** Decode 1.0, 2.0 and 0.5 with `decode` and describe the pattern of the exponent field.
2. **Stretch.** Add to the lesson a function `roots_stable_general(a, b, c)` for any signs of b, using q = -(b + sign(b) sqrt(b^2 - 4ac)) / 2, x1 = q / a, x2 = c / q, and test it on a = 1, b = -1e8, c = 1.
3. **Explain in your own words.** Explain why the stable quadratic formula computes the second root as c / x1 instead of subtracting, using Vieta's relation x1 x2 = c.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
