# Project form (Hello FOSS)

**Project name:** openfloat

**Short description:** Floating-point numbers, rounding error, cancellation, Patriot clock drift and Ariane 5 overflow, in 3 sessions.

**Full description:** openfloat is a beginner-friendly learning repo about the numbers inside computers. In three short sessions you go from the surprise that 0.1 + 0.2 is not 0.3 and a number line whose gaps grow, to the 64-bit IEEE 754 format with machine epsilon, relative error and catastrophic cancellation, to the accumulation of rounding error (naive, Kahan and exact summation of ten million tenths), a calculation that reproduces the commonly cited Patriot clock drift, and the integer overflow behind the Ariane 5 failure. Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment) and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. The repo is intentionally incomplete: a Target animation and a roadmap show where the community can take it next, such as interval arithmetic, other number formats and conditioning.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, JavaScript, LaTeX
