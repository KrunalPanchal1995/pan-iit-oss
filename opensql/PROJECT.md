# Project form (Hello FOSS)

**Project name:** opensql

**Short description:** Learn SQL and database design with nothing to install: queries, keys, joins, indexes and safe transactions in 3 sessions.

**Full description:** opensql is a beginner-friendly learning repo for databases. In three short sessions you go from a table as a grid and a query as a question, to aggregates, keys and the design of tables that store each fact once (third normal form), to joins checked against nested loops, the real cost of a query with and without an index on 200,000 rows, the B-tree idea, atomic transactions, and SQL injection as a defence lesson. It uses only Python's built-in sqlite3 and numpy, and every query is compared with an independent Python computation. Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment) and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. The repo is intentionally incomplete: a Target animation and a roadmap show where the community can take it next, such as composite indexes, concurrency and a query visualiser.

**Technologies (comma-separated):** Python, sqlite3, NumPy, Matplotlib, JavaScript, LaTeX
