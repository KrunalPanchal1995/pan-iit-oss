# Coding tasks: Session 3

1. **Easy.** Change the pKa in `lesson.py` to the value for a weaker acid (pKa 7) and print the half-equivalence pH and the equivalence pH. Predict them first.
2. **Stretch.** Use `find_equivalence` on noisy data with volume noise of 0.1 mL (instead of 0.03) and compare the scatter over 100 seeds with the one printed by the lesson.
3. **Explain in your own words.** Explain, using the charge balance, why 1e-8 mol/L HCl has a pH below 7 and why the formula -log10(C) cannot be right. How would you change the solver to handle a very dilute weak acid?

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
