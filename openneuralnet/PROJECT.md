# Project form (Hello FOSS)

**Project name:** openneuralnet

**Short description:** Build a neural network from scratch in numpy: perceptron, logistic regression, backpropagation and decision boundaries, in 3 sessions.

**Full description:** openneuralnet is a beginner-friendly learning repo that shows what machine learning is and how a neural network learns, with every step written in plain numpy. In three short sessions you go from a single neuron that draws a line and learns by nudging it, to the sigmoid, logistic regression and the XOR problem that no single line can solve, to a two-layer network with hand-coded backpropagation. You test your gradients against finite differences, train on XOR, two moons and two spirals, compare plain SGD, momentum and Adam, and measure overfitting, bad initialisation, a learning rate that is too high and vanishing gradients. Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment) and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. The repo is intentionally incomplete: a Target animation of a boundary morphing while a network trains, and a roadmap, show where the community can go next. This is general education about machine learning, not a tool for real decisions.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, JavaScript, LaTeX
