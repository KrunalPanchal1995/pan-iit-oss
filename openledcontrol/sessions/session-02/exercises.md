# Coding tasks: Session 2

1. **Easy.** Use `trip_lux` to print the trip light level for R = 3.3, 4.7, 6.8 and 10 kilo-ohm at V_th = 2.5 V. Predict the order before you run it.
2. **Stretch.** Write `design_night_light(lux, i_led)` that returns the E12 parts R, R_led and R_B for a V_th = Vcc / 2 design, and test it for 30 lux and 15 mA.
3. **Explain in your own words.** Explain why a LDR in the top position of the divider and the LDR in the bottom position give opposite behaviour (voltage falls or rises with light).

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
