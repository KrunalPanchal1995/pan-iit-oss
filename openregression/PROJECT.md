# Project form (Hello FOSS)

**Project name:** openregression

**Short description:** Fit lines to rainfall and yield data, measure uncertainty, and learn to spot overfitting, in 3 sessions.

**Full description:** openregression is a beginner-friendly learning repo about predicting a number from data, with crop yield as the running example. In three short sessions you go from drawing a line through dots and finding the one that misses least, to the normal equations, R squared, residual plots, two-input regression and a prediction interval whose coverage you test by simulation, and finally to overfitting: polynomial degree against test error, ridge regression, k-fold cross-validation, bias and variance, robust lines, confounders and collinear inputs. Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment) and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. All data are synthetic, so you can check every fit against the truth that generated it. The repo is intentionally incomplete: a Target animation and a roadmap show where the community can take it next, such as heteroscedastic intervals, sparse models and quantile regression.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, JavaScript, LaTeX
