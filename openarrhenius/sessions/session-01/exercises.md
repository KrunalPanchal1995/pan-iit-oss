# Coding tasks: Session 1

1. **Easy.** Print k for Ea = 100 and Ea = 200 kJ/mol at 500, 800 and 1100 K and predict which one rises faster before you run it.
2. **Stretch.** Change the noise in `make_data` to 0.15 and then to 0.01 and compare the fitted Ea each time; explain what you see.
3. **Explain in your own words.** Explain, using the Arrhenius law, why the speed-up from 600 to 700 K (73.4) is larger than from 700 to 800 K (25.1) for the same 100 K step.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
