# Coding tasks: Session 1

1. **Easy.** Compute `probabilities(prepare(theta))` for theta = 30, 90 and 150 degrees and predict first which gives the largest P1.
2. **Stretch.** Write `phase_for_p0(p0)` that returns the smallest phase in degrees (0 to 180) that gives the exit 0 probability p0, using `numpy.arccos`, and test it with 0.75 (it should give 60).
3. **Explain in your own words.** Explain why the probabilities P0 and P1 always add up to 1 after any phase shift and any number of beam splitters.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
