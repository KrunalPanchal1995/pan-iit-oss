# Coding tasks: Session 2

1. **Easy.** Print `to_base(n, 2)` and `to_base(n, 16)` for n = 255, 256 and 4095. Predict each by hand first.
2. **Stretch.** Write `nor_n(a, b)` using only NAND gates (NOR is NOT of OR) and check it on all four input rows. How many NAND gates did you use?
3. **Explain in your own words.** Design a 3-input odd-parity gate (output 1 when an odd number of inputs are 1). Write its sum of products with `minterms` and verify it on all 8 rows.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
