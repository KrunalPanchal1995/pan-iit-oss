# Coding tasks: Session 3

1. **Easy.** Print the gate count and the carry delay of `build_adder(n)` for n = 1, 2, 3, 4. Predict each from 5n and 2n + 1 first.
2. **Stretch.** Use `add_sub` to find all pairs of 4-bit signed numbers (a, b) with a - b overflowing, and count them. Plot them like the overflow map.
3. **Explain in your own words.** Stretch: build a seven-segment decoder segment 'a' with sum of products from `SEGMENTS`: list which digits light segment a, make the minterms of the 4-bit digit code, and check your circuit against `seven_segment` for the digits 0 to 9.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
