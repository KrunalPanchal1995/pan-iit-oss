# Coding tasks: Session 1

1. **Easy.** Use `to_bits` to print the switches for 0, 5, 10 and 15. Predict each pattern by hand before you run it.
2. **Stretch.** Write `count_up(start, steps)` that returns the lamp strings for `steps` numbers starting at `start`, using `add_one` so that it wraps at 15.
3. **Explain in your own words.** Explain, using the counting table, why the rightmost column flips on every row, the next one every second row, and so on.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
