openbinary

Build an adder from logic gates and see how computers count, in five sessions.

  • Session 1: Switches, lamps and counting in binary (Level 1, 60 min)
  • Session 2: Number systems, logic gates and Boolean algebra (Level 2, 75 min)
  • Session 3: Build an adder from gates and see how computers count (Level 3, 90 min)
  • Session 4: A carry-lookahead adder (Level 3, 90 min)
  • Session 5: A multiplier from gates (Level 3, 90 min)
