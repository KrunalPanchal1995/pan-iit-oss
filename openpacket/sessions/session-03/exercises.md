# Coding tasks: Session 3

1. **Easy.** Run `utilisation(2000, 12000, W)` for W = 2, 3 and 5 and compare each result with `utilisation_formula`. Predict the first one by hand.
2. **Stretch.** In `reroute_experiment` set `interval=0.002` and predict how many packets are lost with the same detection time of 0.05 s before you run it.
3. **Explain in your own words.** Explain why in the toy AIMD model a buffer of 20 packets keeps the pipe full while a buffer of 0 gives about 75 percent, using the peak and low values of the sawtooth.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
