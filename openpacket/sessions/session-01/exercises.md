# Coding tasks: Session 1

1. **Easy.** Change the message in `lesson.py` to the text of a short poem as bytes, cut it into 20 byte packets, shuffle them and rebuild it. Print whether the result equals the original.
2. **Stretch.** Add a router to `NEXT_HOP` so the route has 7 nodes, and predict `journey_steps(4, 6)` before you run it.
3. **Explain in your own words.** Explain why the best packet size would move to larger values if the label shrank to 10 bytes. Then check it with `delivery_time_ms` after setting `HEADER_BYTES = 10`.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
