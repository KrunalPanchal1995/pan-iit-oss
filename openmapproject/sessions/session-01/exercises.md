# Coding tasks: Session 1

1. **Easy.** Change the latitude in `lesson.py` to 45 and 75 degrees. Predict the stretch with your calculator before you run it.
2. **Stretch.** Write `latitude_for_stretch(s)` that returns the latitude (in degrees) where the east-west stretch equals s. Check that it returns 60 for s = 2.
3. **Explain in your own words.** Explain, using the orange, why the stretch becomes infinite at the pole. Why is it still sensible to say the pole is a single point?

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
