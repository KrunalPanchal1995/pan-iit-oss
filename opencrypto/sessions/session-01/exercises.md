# Coding tasks: Session 1

1. **Easy.** Use `caesar_encrypt` to encrypt your own name with key 7, then decrypt it with `caesar_decrypt`. Predict the first letter by hand before you run it.
2. **Stretch.** Write `rot13(text)` (key 13) and check that applying it twice gives back the original. Explain why only key 13 does this.
3. **Explain in your own words.** Explain why the readability score might pick the wrong key for the three-letter message CAT, and what you could change (a longer message, or a better score).

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
