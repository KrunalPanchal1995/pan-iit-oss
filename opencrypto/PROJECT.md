# Project form (Hello FOSS)

**Project name:** opencrypto

**Short description:** Break and fix toy ciphers, and learn why keys, key size and hashing matter: 3 sessions of cybersecurity basics.

**Full description:** opencrypto is a beginner-friendly learning repo about encryption basics and the idea that security rests on the key. In three short sessions you encrypt a message with the Caesar shift and discover why anyone can try all 25 shifts, count the keys of a substitution cipher (26! of them) and still break it by counting letters, meet the Vigenere cipher and the index of coincidence, and then study the one-time pad, a toy stream cipher with a short key, SHA-256 hashing, salted password hashes, HMAC and the time it takes to try every key of 40, 56, 80 and 128 bits. Every session follows the same six steps (real-world problem, theory, visual explanation, interactive simulation, worked example, assessment) and has a lesson script, a Colab notebook, a live slider app and a checkpoint that prints PASS or FAIL. This is defensive education: toy ciphers and standard textbook results only. Real systems must use vetted libraries, never home-made cryptography. The repo is intentionally incomplete: a Target animation and a roadmap show where the community can go next.

**Technologies (comma-separated):** Python, NumPy, Matplotlib, hashlib, hmac, JavaScript, LaTeX
