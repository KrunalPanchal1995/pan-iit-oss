# Coding tasks: Session 1

1. **Easy.** Change the numbers in `lesson.py` to convert 5 knots to km/h. Predict the answer before you run it.
2. **Stretch.** Write `to_si(value, unit)` that returns the value in SI for any speed unit and test it on all five units.
3. **Explain in your own words.** Explain why the lines in the graph all start at zero and why a unit with a bigger size has a steeper line.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
