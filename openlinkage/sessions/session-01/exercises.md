# Coding tasks: Session 1

1. **Easy.** Run the lesson, then change the crank length to 1.5 in `rocker_swing` and print the swing. Predict it first from the table in Section F.
2. **Stretch.** Write `coupler_curve` for k = 1 and k = 1.5 and print the highest y reached by each curve. Which k draws the taller curve, and why?
3. **Explain in your own words.** Explain, with a sketch, why the rocker has exactly two possible positions for a given crank angle and why the second one is the mirror image of the first.

Not sure where to start? Change one number in `lesson.py`, predict what happens, then run it.
